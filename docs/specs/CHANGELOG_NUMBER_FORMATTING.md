# Changelog: Number Formatting Update

## Дата: 2026-02-13

## Описание изменений

Добавлено форматирование больших чисел с разделителями разрядов для улучшения читаемости.

### Правило форматирования

Числа от **100 000** и выше теперь отображаются с пробелами в качестве разделителей разрядов:
- `100000` → `100 000`
- `1234567` → `1 234 567`
- `-500000` → `-500 000`

Числа меньше 100 000 отображаются без изменений:
- `99999` → `99999`
- `50` → `50`

### Новый модуль

**`bot/utils/formatters.py`**
- Функция `format_number(num: int | float) -> str`
- Универсальная утилита для форматирования чисел во всём проекте

### Примеры использования

```python
from bot.utils.formatters import format_number

# В коде
balance = 1500000
await message.reply(f"Ваш баланс: {format_number(balance)} очков")
# Вывод: "Ваш баланс: 1 500 000 очков"

# Маленькие числа
small_amount = 500
await message.reply(f"Вы выиграли {format_number(small_amount)} очков")
# Вывод: "Вы выиграли 500 очков"
```
