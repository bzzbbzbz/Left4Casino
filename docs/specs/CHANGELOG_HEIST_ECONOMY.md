# Changelog: Heist Economy Update

## Дата: 2026-02-13

### Изменения в экономике ограбления банка

#### 1. Новая логика спинов

**Было:**
- Любой спин: ставка списывается
- Проигрыш: ставка → в банк
- Выигрыш: ставка + виртуальный выигрыш → в банк (игрок НЕ получает выигрыш)

**Стало:**
- Проигрыш: ставка списывается и идёт в банк
- Выигрыш: игрок получает выигрыш как обычно (банк НЕ пополняется)

**Результат:**
- Банк растёт в ~2-3 раза медленнее
- Дефляционная модель (чистая инфляция = 0%)
- Деньги только перераспределяются между игроками

#### 2. Убраны спам-сообщения

**Было:**
После каждого спина бот отправлял:
```
🏦 Ваша ставка (10) и выигрыш (70) ушли в банк ограбления!
💰 В банке: 20709
💳 Ваш баланс: 4730
```

**Стало:**
- Сообщения только для выигрышей (как в обычном режиме)
- Информация о банке — только в периодических сообщениях крупье (каждые 2 мин)
- Проигрыши — удаление сообщения через минуту (как обычно)

#### 3. Замена @nickname на имена

**Было:**
```
🏃 Сейчас с добычей уйдёт: @username
```

**Стало:**
```
🏃 Сейчас с добычей уйдёт: Имя
```

**Результат:**
- Игроки не получают лишние оповещения
- Меньше спама в чате

#### 4. Обновлены параметры конфигурации

| Параметр | Было | Стало | Причина |
|----------|------|-------|---------|
| `pot_cap_pct` | 50% | 5% | Банк растёт медленнее |
| `min_pot_pct` | 10% | 1% | Соответствие pot_cap |
| `seed_min_pct` | 5% | 0.5% | Пропорционально pot_cap |
| `seed_max_pct` | 10% | 1.5% | Пропорционально pot_cap |

#### 5. Примеры масштабирования (B = 50 000)

| Параметр | Было (50%) | Стало (5%) |
|----------|------------|------------|
| pot_cap | 25 000 | 2 500 |
| min_pot | 5 000 | 500 |
| seed | 2 500-5 000 | 250-750 |
| Макс. выплата | 17 500 | 1 750 |

#### 6. Изменения в коде

**Файлы:**
- `bot/handlers/group_games.py` — новая логика обработки спинов
- `bot/services/heist.py` — обновлён `process_spin()`, заменён `nickname` на `first_name`
- `settings.example.toml` — обновлены дефолтные значения
- `HEIST_SPEC.md` — обновлена документация
- `AGENTS.md` — обновлена документация

**Логирование:**
- `heist_contribution` — теперь только для проигрышей
- `win` / `loss` — обычные события с флагом `during_heist: true` в metadata

## Влияние на игровой процесс

### Для игроков:
- ✅ Выигрыши теперь получают игроки (как обычно)
- ✅ Меньше спама в чате
- ✅ Нет лишних оповещений
- ⚖️ Банк растёт медленнее → ивент может длиться дольше

### Для экономики:
- ✅ Дефляционная модель (инфляция минимальна)
- ✅ Деньги только перераспределяются
- ✅ Комиссия крупье (рекомендуется 15%) уничтожается из экономики
- ⚖️ Макс. выплата увеличена с 3.5% до 4.25% от B (при commission=15%)

### Для баланса:
- ✅ Киту теперь выгодно играть (может выиграть банк с минимальными вложениями)
- ✅ Активным чатам легче достичь pot_cap
- ✅ Тихие чаты получают пропорциональные награды
